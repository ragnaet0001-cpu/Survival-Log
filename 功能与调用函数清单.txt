======================================================================

  [LogInfo] void LogInfo(string msg)
      -> (无游戏 API 直调，纯逻辑)

  [LogErr] void LogErr(string msg)
      -> (无游戏 API 直调，纯逻辑)

  [AddGold] bool AddGold(int amount)
      -> player.AddGold

      -> player.SyncGold

  [CurrentGold] int CurrentGold()
      -> UserComponent.Money（玩家金币真源，购买判定读它）

  [AddItem] bool AddItem(int configId, int count)
      -> BackpackManager.AddItem(configId, count, ...)
        内部：ItemManager.GetItemData(configId) -> ItemData.ItemCount 修改 -> ItemManager.SetItemCount / ForceRemoveItem

  [ListBackpackItems] System.Collections.Generic.List<BackpackItemView> ListBackpackItems()
      -> items.GetItemDataList

  [SetBackpackItemCount] bool SetBackpackItemCount(long instanceId, int newCount)
      -> items.GetItemData
      -> val.StackLimit
      -> items.SetItemCount

  [DuplicateBackpackItem] bool DuplicateBackpackItem(long instanceId)
      -> items.GetItemData

  [RemoveBackpackItem] bool RemoveBackpackItem(long instanceId)
      -> items.GetItemData
      -> items.ForceRemoveItem

  [GetAttr] int GetAttr(AttrName name)
      -> AttributeComponent.GetTotalValue_Float(name)（内部 x1000 存储）

  [GetMaxAttr] int GetMaxAttr(AttrName name)
      -> AttributeComponent.GetTotalValue_Float(maxName)（Max 系列 = 核心属性+100）

  [GetAttributeSourceId] long GetAttributeSourceId()
      -> (无游戏 API 直调，纯逻辑)

  [SetAttr] bool SetAttr(AttrName name, int value)

  [TryGetMoveSpeed] bool TryGetMoveSpeed(out float current, out float original, out float multiplier)

  [SetMoveSpeedMultiplier] bool SetMoveSpeedMultiplier(float multiplier)
      -> AttributeComponent.SetBaseValue_Float(AttrName.MoveSpeed=401, 原始移速*倍率, true) + SyncAttr2UI(401)

  [SetHomeDurability] bool SetHomeDurability(int slotTypeId, int value, out int updated)

六、游戏更新后如何适配（更新指南）
======================================================================
架构上这是 BepInEx 6 IL2CPP 插件，游戏更新后的适配流程：

1. 【自动重新生成 interop】
   - BepInEx 启动时对比 BepInEx\interop\assembly-hash.txt 与当前 GameAssembly.dll
   - 游戏更新后 hash 变化 -> BepInEx 自动用 Cpp2IL 重新生成 interop（无需手动）
   - 若没自动生成：删除 BepInEx\interop\ 整个目录后重启游戏即可

2. 【插件 DLL 一般不用重编译】
   - 插件代码按"名称"绑定游戏类型（Il2CppInterop 生成），游戏更新不改变
     类名/方法名/字段名时，旧 DLL 直接能用
   - 改名/改签名 -> 该功能运行时报错，日志可见

3. 【Harmony 补丁失败】
   - 12 个补丁类各自 try-catch，单个失败不影响其他
   - 日志 "[Harmony] xxx 补丁失败" -> 对应功能失效，需要按新版方法签名更新补丁类

4. 【排查流程】
   - 游戏更新后重启 -> 看 BepInEx\LogOutput.log
   - 检查：interop 是否重新生成 / 插件是否加载 / 有无补丁失败 / 有无功能异常
   - 需要改代码时：改 SurvivalLogMod 工程 -> dotnet build -> 拷贝 DLL 到
     E:\Program Files (x86)\Survival Log\BepInEx\plugins\SurvivalLogMod\

5. 【Unity 大版本升级】
   - BepInEx 会自动下载匹配 unity-libs（UnityBaseLibrariesSource）
   - 若 BepInEx 本体不兼容新版 Unity，需更新 BepInEx 6 本体（core 目录整体替换）
